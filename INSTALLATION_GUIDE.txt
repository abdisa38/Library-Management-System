PROJECT OVERVIEW
================
A complete, production-ready Library Management System built with:
- Frontend: HTML5, CSS3, JavaScript (Vanilla JS)
- Backend: PHP 8+
- Database: MySQL
- Architecture: MVC Pattern
- Features: Role-Based Access Control, Book Management, Borrowing System,
  Automatic Fine Calculation, Reports & Analytics

INSTALLATION STEPS
==================

1. PREREQUISITES
   - XAMPP (Apache, MySQL, PHP 8+)
   - Modern web browser

2. SETUP DATABASE
   - Start XAMPP Control Panel
   - Start Apache and MySQL services
   - Open phpMyAdmin: http://localhost/phpmyadmin
   - Create new database: library_management_system
   - Import SQL file: database/library_management_system.sql

3. CONFIGURATION
   - Open: config/database.php
   - Verify database credentials:
     * DB_HOST: localhost
     * DB_USER: root
     * DB_PASS: (empty for default XAMPP)
     * DB_NAME: library_management_system

4. ACCESS THE SYSTEM
   - URL: http://localhost/Library-Management-System/
   - You will be redirected to login page

SYSTEM SETTINGS
===============
Edit config/config.php to customize:

FINE_PER_DAY = 1.00           (Fine amount per overdue day)
MAX_BORROW_DAYS = 14          (Maximum borrow period)
MAX_BOOKS_PER_STUDENT = 5     (Maximum books per student)
SESSION_TIMEOUT = 1800        (Session timeout in seconds)

TROUBLESHOOTING
===============

Problem: Cannot connect to database
Solution:
- Verify MySQL is running in XAMPP
- Check database credentials in config/database.php
- Ensure database was imported successfully

Problem: Login not working
Solution:
- Clear browser cache and cookies
- Verify credentials in database
- Check if PHP sessions are enabled

Problem: Book covers not uploading
Solution:
- Check folder permissions for uploads/book_covers/
- Verify upload_max_filesize in php.ini
- Ensure file type is JPG, PNG, or GIF

Problem: Page not found (404)
Solution:
- Verify Apache is running
- Check file paths are correct
- Ensure files are in htdocs folder

USAGE GUIDE
===========

FOR SUPER ADMIN:

1. Managing Books:
   - Go to "Manage Books"
   - Click "Add New Book"
   - Fill in: Title, Author, ISBN, Publisher, Year, Quantity, Category
   - Upload book cover (optional)
   - Click "Submit"

2. Managing Users:
   - Go to "Manage Users"
   - Click "Add New User"
   - Fill in user details
   - Select role (Super Admin/Librarian/Student)
   - Click "Submit"

3. Viewing Reports:
   - Navigate to desired report (Borrow/Return/Fine)
   - Select date range (optional)
   - Export to CSV or print

FOR LIBRARIAN:

1. Issuing a Book:
   - Go to "Issue Book"
   - Enter Student ID
   - Search and select book
   - Set due date (default 14 days)
   - Click "Issue Book"

2. Returning a Book:
   - Go to "Return Book"
   - Enter Student ID or Book ISBN
   - View list of borrowed books
   - Click "Return" button
   - System auto-calculates fine if overdue

3. Managing Fines:
   - Go to "Fine Management"
   - View all outstanding fines
   - Update payment status
   - Generate fine reports

FOR STUDENTS:

1. Browsing Books:
   - Go to "Available Books"
   - Use search bar to find books
   - Filter by category
   - Click on book to view details

2. Checking Borrowed Books:
   - Go to "My Borrowed Books"
   - View all currently borrowed books
   - Check due dates
   - View any pending fines
